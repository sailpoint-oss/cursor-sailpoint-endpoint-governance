# SailPoint Endpoint Governance

SailPoint Endpoint Governance checks your AI agent's tool calls against your organization's SailPoint policies before they run, and records each call for audit.

**To enable SailPoint Endpoint Governance, please reach out to your administrator.** It is set up
and turned on for you by your organization's SailPoint administrator.

This listing has no hooks, commands or servers. It runs nothing, reads nothing
on your machine and sends no data anywhere. Installing it has no effect on
Cursor.
